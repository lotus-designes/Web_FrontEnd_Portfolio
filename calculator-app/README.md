# Pinky Calculator Web App

A simple and stylish calculator web application built using HTML, CSS, and JavaScript.
This project was developed as part of my work in 2025.

---

## Overview

Pinky Calculator is a responsive web-based calculator with a soft UI design and dark mode support.
It allows users to perform basic arithmetic operations بسهولة وبواجهة جذابة.

---

## Features

* Basic arithmetic operations (addition, subtraction, multiplication, division)
* Percentage calculation support
* Keyboard input support
* Delete last character (Backspace)
* Clear display (AC)
* Dark mode toggle
* Responsive design for different screen sizes
* Clean and modern user interface

---

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

---

## How to Use

1. Open the project in your browser
2. Use the buttons or keyboard to enter numbers and operations
3. Press "=" or Enter to calculate
4. Use "AC" to clear the display
5. Use "⌫" to delete the last input
6. Toggle dark mode using the button in the corner
