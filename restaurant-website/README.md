# FoodEat Restaurant Website

A modern and responsive restaurant website built using HTML and CSS.
This project was developed as part of my work in 2025.

---

## Overview

FoodEat is a multi-page restaurant website that showcases a food menu, featured dishes, and services.
The design focuses on clean layout, visual appeal, and responsive behavior across devices.

---

## Features

* Responsive design for mobile, tablet, and desktop
* Attractive hero section with call-to-action buttons
* Navigation bar with multiple pages
* Featured menu section (Top List)
* Product cards with images and pricing
* Services section with icons
* Separate food ordering page
* Smooth hover effects and UI interactions
* Background image with blur effect

---

## Pages Included

* Home page (main landing page)
* Menu page
* Orders page

---

## Technologies Used

* HTML5
* CSS3
* Boxicons (for icons)

---

## How to Use

1. Open the main HTML file in your browser
2. Navigate using the menu links
3. Explore the food menu and featured items
4. Open the order page to view available dishes
